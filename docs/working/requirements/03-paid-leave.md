# 有給休暇申請機能 — 要求仕様 Q&A

## ユーザーストーリー（案）

| ID | ストーリー |
|----|-----------|
| LEAVE-01 | 社員として、有給休暇を申請したい（日付・理由を指定） |
| LEAVE-02 | 上長として、部下の有給休暇申請を承認/却下したい |
| LEAVE-03 | 社員として、自分の有給休暇の残日数を確認したい |
| LEAVE-04 | 社員として、自分の申請履歴を確認したい |
| LEAVE-05 | 管理者として、全社員の有給取得状況を確認したい |

---

## 仕様確認事項

[Question 1] 有給休暇の付与ルール（残日数の管理）はどこまで実装しますか？
- (A) 固定の初期残日数を持ち、申請承認で減算するだけ（シンプル）
- (B) 入社日ベースで労基法に準じた自動付与（6ヶ月→10日、1.5年→11日…）
- (C) 管理者が手動で付与日数を設定する

[Answer 1]
- (B) 入社日ベースで労基法に準じた自動付与（6ヶ月→10日、1.5年→11日…）
---

[Question 2] 半日休暇（午前休・午後休）は対応しますか？
- (A) 1日単位のみ
- (B) 半日単位も対応する

[Answer 2]
- (B) 半日単位も対応する
---

[Question 3] 申請は何日前から可能ですか？また過去日の申請（事後申請）は許可しますか？
- (A) 未来日のみ（当日以降）
- (B) 過去日も申請可能（事後申請OK）

[Answer 3]
- (B) 過去日も申請可能（事後申請OK）
---

[Question 4] 承認者は誰ですか？
- (A) 同じ部署の isManager=true の社員（修正申請と同じパターン）
- (B) 別途承認者を設定する仕組みが必要

[Answer 4]
- (A) 同じ部署の isManager=true の社員（修正申請と同じパターン）
---

[Question 5] 月次レポートや勤怠履歴との連携はどこまで行いますか？
- (A) 有給取得日を勤怠履歴に表示し、欠勤日数から除外する
- (B) 有給は独立した画面のみで、既存の勤怠履歴・レポートには影響させない

[Answer 5]
- (A) 有給取得日を勤怠履歴に表示し、欠勤日数から除外する
---

## 追加確認事項

[Question 6] 連続休暇（複数日）の申請方法は？
- (A) 1申請につき1日のみ（複数日は個別申請）
- (B) 開始日〜終了日を指定して一括申請できる

[Answer 6]
- (A) 1申請につき1日のみ（複数日は個別申請）
---

[Question 7] 申請のキャンセルは可能ですか？
- (A) 承認前のみキャンセル可能
- (B) 承認後もキャンセル可能（承認者に通知）
- (C) キャンセル不可（却下→再申請の運用）

[Answer 7]
- (C) キャンセル不可（却下→再申請の運用）
---

[Question 8] 有給残日数が 0 の場合の振る舞いは？
- (A) 申請不可（エラーで弾く）
- (B) 警告を表示するが申請自体は可能（欠勤扱い等は運用で対応）

[Answer 8]
- (A) 申請不可（エラーで弾く）
---

[Question 9] 有給付与のタイミングについて。労基法の付与日数テーブルを実装しますが、年度の起点はどうしますか？
- (A) 入社日起点（入社日から6ヶ月後に初回付与、以降1年ごと）
- (B) 会社の年度起点（例: 4月1日に一斉付与、入社初年度は按分）

[Answer 9]
- (B) 会社の年度起点（例: 4月1日に一斉付与、入社初年度は按分）
