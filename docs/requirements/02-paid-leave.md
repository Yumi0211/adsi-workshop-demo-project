# 有給休暇申請機能 — 要求仕様

## ユーザーストーリー

| ID | アクター | ストーリー | 受け入れ基準 |
|----|---------|-----------|-------------|
| LEAVE-01 | 社員 | 有給休暇を申請したい（日付・種別・理由を指定） | 残日数 > 0 のとき申請できる。残日数 0 ならエラー |
| LEAVE-02 | 上長 | 部下の有給休暇申請を承認/却下したい | 承認→残日数減算、却下→理由入力必須 |
| LEAVE-03 | 社員 | 自分の有給休暇の残日数を確認したい | 付与日数・使用日数・残日数が表示される |
| LEAVE-04 | 社員 | 自分の申請履歴を確認したい | ステータス（申請中/承認/却下）が一覧で見える |
| LEAVE-05 | 管理者 | 全社員の有給取得状況を確認したい | 部署別にフィルタ可能 |
| LEAVE-06 | 社員 | 半日休暇（午前休・午後休）を申請したい | 半日=0.5日として残日数から減算 |

## 確定仕様

### 付与ルール

- **労基法準拠の自動付与**
- **年度起点**: 会社年度（4月1日）に一斉付与。入社初年度は按分
- 付与日数テーブル（労基法第39条）:

| 勤続年数 | 付与日数 |
|---------|---------|
| 0.5年（初回） | 10日 |
| 1.5年 | 11日 |
| 2.5年 | 12日 |
| 3.5年 | 14日 |
| 4.5年 | 16日 |
| 5.5年 | 18日 |
| 6.5年以上 | 20日 |

- 初年度按分: 入社日から年度末（3/31）までの残月数に応じて按分（端数切り上げ）

### 申請

- **1申請につき1日**（複数日は個別申請）
- **半日単位対応**: 全日 / 午前休 / 午後休 を選択
- **過去日の事後申請OK**（当日・過去日・未来日いずれも申請可能）
- **残日数 0 の場合は申請不可**（エラーで弾く）
- **キャンセル不可**（却下→再申請の運用）
- 理由は任意入力

### 承認

- **承認者**: 同部署の `isManager=true` の社員（修正申請と同じパターン）
- 承認 → 残日数を減算（半日休なら 0.5 減算）
- 却下 → 却下理由を入力必須。残日数は変動しない

### 勤怠連携

- **有給取得日を勤怠履歴に表示**（ステータス: 有給 / 午前有給 / 午後有給）
- **月次レポートの欠勤日数から有給取得日を除外**
- 月次サマリーに有給取得日数を追加表示

## スコープ外（今回は対応しない）

- 繰越ルール（前年度未消化分の繰越上限）
- 時間単位の有給取得
- 特別休暇（慶弔・育児等）
- メール/Slack 通知
